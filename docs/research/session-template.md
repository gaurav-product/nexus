# Session template — comparative concept session (25 min)

Run **after** the participant's interview and diary, never before. Use the in-app Research session (`/research` in the demo) on the facilitator's laptop, screen-shared or side by side. It handles counterbalancing and records answers to CSV.

## Before the session
- [ ] Consent for "example-screens session" ticked ([consent-template.md](consent-template.md))
- [ ] Participant ID assigned (P0x). The ID's number sets the view rotation, so don't reuse IDs.
- [ ] Demo open at Research, all sources on (check the Sources page)
- [ ] Observation sheet ready ([observation-template.md](observation-template.md))

## Script (read verbatim)

**Intro (2 min)**
> "I'm going to show you four short situations using made-up data about a person called Riya. For each one, you'll first see one view and I'll ask what you'd do. Then you'll see three views side by side. The views were made by different approaches; I'm interested in which one works for you, and it's fine to dislike all of them. There's no wrong answer, and you won't hurt my feelings."

**Per scenario (5 min × 4)**
1. Show the single first view. Ask: *"What, if anything, would you do next?"* Wait. Don't hint. Type their words.
2. Code the answer (hidden panel) against the expected action shown to you.
3. Click **Compare views**. Ask: *"Which of these makes it clearest what to do? Which would you trust most?"* Then *"Why?"* — note the reason on the observation sheet.
4. Ratings for the view the app names. Read each item aloud.
5. *"How often does something like this happen to you?"* If they start telling a story, let them; note specifics (when, which tools, what happened) in "real time this happened".

**Close (3 min)**
- Overall preference; what they'd connect; *"What would need to be true before you connected it?"*
- Ask about a future pilot with their own account. Record contact details **outside the app**.
- Save. Only now reveal which view was which, if they ask.

## Facilitator rules
- Don't say "Nexus", "my product", or "the AI one" before the reveal.
- Don't explain a view. If they're confused, that's data — note it, then say *"Take your time."*
- If they ask "which one did you build?", answer: *"I'll tell you at the end — it helps me not bias you."*
- Positive reactions are not validation. Code everything with the [evidence rubric](evidence-rubric.md).

## After the session (10 min)
- Export CSV from Research, paste into the private sheet.
- Complete the observation sheet while fresh.
- Add a line to [validation-log.md](validation-log.md) (no identifying details).
